
# Adeyanju Azezz — Graphic Designer/Product Designer Portfolio

## Project Overview

A modern, responsive personal portfolio website designed to showcase my Graphic Designer/Product Designer skills, projects, and professional experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Google Fonts

## Features

- Responsive navigation
- Modern hero section
- Featured projects
- About Me section
- Contact section
- Responsive project layouts
- Smooth scrolling
- CSS-generated project artwork

## Installation

1. Clone or download the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.

Update the following:

- Email address
- GitHub profile link

- Project links
- Project screenshots
- About Me description
